# 設計書項目定義書

## 1. 目的

本書は、設計書体系定義書（STD-002）で定義した各設計書について、次の事項を定義する。

- 各設計書の責務（一文で表した「この設計書が答える問い」）
- 各設計書に記載する項目（章構成と項目）
- 各項目の要否と、その情報の「正」がどこにあるか

本書は、テンプレート（02_テンプレート）と作成ガイド（01_作成ガイド）の設計図となる。テンプレートの章・項目は本書に従って作成し、本書にない項目をテンプレートに追加する場合は先に本書を更新する。

## 2. 本書の読み方

### 2.1 共通章の扱い

設計書作成規約（STD-003）7.2 の必須章のうち、次の章はすべての設計書に共通するため、本書では記載を省略する。本書の項目表は「4. 仕様」章に記載する内容を示す。

| 共通章 | 記載場所 |
|--------|----------|
| 1. 目的／2. 対象範囲／3. 前提・制約 | 各設計書の冒頭 |
| 5. 関連資料／6. 未確定事項／7. 変更履歴 | 各設計書の末尾 |

### 2.2 項目表の列

| 列 | 意味 |
|----|------|
| No | 項目番号。テンプレートの章番号（4.x）に対応する |
| 項目 | 項目名 |
| 記載内容 | 何を書くか |
| 要否 | ◎ 必須／○ 条件付き必須（条件を併記）／△ 任意 |
| 工程 | 基 = 基本設計で記載／詳 = 詳細設計で追記（基本・詳細の両方にまたがる設計書のみ） |
| 情報源 | 正 = この設計書が正として定義する／参照(XXX) = XXX が正。ID・リンクで参照し、転記しない |

### 2.3 一覧ファイルと個別ファイル

要素ごとにファイルを分ける設計書（画面・API・テーブル・処理など）は、「一覧ファイル」と「個別ファイル」の2種類で構成する。本書では両方の項目を定義する。
