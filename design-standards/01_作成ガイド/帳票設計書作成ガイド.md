# 帳票設計書作成ガイド

本ガイドは、DOC-206 帳票設計書の各項目に何をどこまで書くかを説明する。共通のルールは設計書作成規約（STD-003）に従う。

## 1. この設計書の役割

**帳票・出力ファイルには、何が、どの形式で、いつ出力されるか。**

| 項目 | 内容 |
|------|------|
| 目的 | 帳票・出力ファイル（PDF、CSV等）のレイアウト・項目・出力条件を定義する |
| 書かないこと | 帳票を生成する内部処理（→ DOC-301） |
| 作成条件 | 帳票・ファイルを出力するシステム |
| 要否 | 条件付き必須 |
| ファイル単位 | 帳票ごとに1ファイル |
| テンプレート | [帳票設計書_テンプレート](../02_テンプレート/基本設計/帳票設計書_テンプレート.md) |

## 2. 作成の流れ

| 項目 | 内容 |
|------|------|
| 作成する工程 | 基本設計 |
| 作成前に読むもの（入力情報） | DOC-103 機能一覧、DOC-204 DB設計書 |
| この設計書が正として定義するもの | 帳票一覧、レイアウト、出力項目と編集仕様、出力条件 |
| 関連設計書 | DOC-301、DOC-402 |

## 3. 項目別の記載ガイド

記載例は、共通の題材「個人向けタスク管理Webアプリ TaskNote」に基づく（03_記載例 参照）。要否・情報源の記号は設計書項目定義書（STD-004）2.2 に従う。

| No | 項目 | 記載内容 | 要否 | 情報源 | 記載例 |
|----|----|----|----|----|----|
| 4.1 | 帳票一覧（一覧ファイル） | 帳票ID（RPT）、帳票名、形式（PDF/CSV/Excel）、対応機能、出力契機 | ◎ | 正 | RPT-001｜タスク一覧CSV｜CSV｜FNC-004｜画面操作 |
| 4.2 | 帳票概要 | 目的、利用者、出力契機（画面操作／バッチ） | ◎ | 正 | RPT-001｜タスクを表計算ソフトで見る｜会員｜タスク一覧画面のエクスポート |
| 4.3 | レイアウト | 用紙・ページ構成、またはファイルの列構成 | ◎ | 正 | 列：タスク名、期限、状態 |
| 4.4 | 出力項目 | 項目、データ出所、編集仕様（書式、丸め、ゼロ埋め） | ◎ | 正（出所は参照） | 2｜期限｜tasks.due_date｜YYYY-MM-DD |
| 4.5 | 出力条件 | 抽出条件、並び順、改ページ条件、集計 | ◎ | 正 | 並び順：期限の昇順 |
| 4.6 | ファイル仕様 | ファイル名規則、文字コード、区切り文字、ヘッダー有無 | ○ ファイル出力 | 正 | 文字コード：UTF-8（BOM付き） |

## 4. 書き方のポイント

- 出力項目ごとにデータ出所と編集仕様（書式・丸め）を書く。
- CSV などのファイル出力は、受け取る側が困らないよう文字コード・改行・区切りを明記する。

## 5. よくある誤り

- 帳票を作る内部処理を書く → 処理設計書に書く。

## 6. レビュー観点

設計書作成規約（STD-003）14.2 の共通レビュー観点に加えて、次を確認する。

| No | 確認内容 |
|----|----------|
| 1 | すべての出力項目にデータ出所があるか。 |
| 2 | 抽出条件・並び順が決まっているか。 |

## 7. 小規模（規模S）での簡略化

帳票が1〜2個なら、帳票一覧を省略して帳票ごとのファイルだけでよい。
