# 設計書標準（design-standards）

特定の言語・フレームワークに依存せず、小規模から大規模まで使える設計書の標準体系です。

## 構成

| ディレクトリ | 内容 | 状態 |
|--------------|------|------|
| [00_標準定義/](00_標準定義/) | 方針書・体系定義書・作成規約 | ドラフト v0.1.0 |
| 01_作成ガイド/ | 設計書ごとの作成ガイド | 未着手（第3段階） |
| 02_テンプレート/ | 工程別のテンプレート | 未着手（第3段階） |
| 03_記載例/ | テンプレートの記入例 | 未着手（第3段階） |

## 標準定義ドキュメント

| ID | ドキュメント | 答える問い |
|----|--------------|------------|
| STD-001 | [設計書標準化方針書](00_標準定義/01_設計書標準化方針書.md) | なぜ、どのような考え方で設計書を作るのか |
| STD-002 | [設計書体系定義書](00_標準定義/02_設計書体系定義書.md) | どの設計書が必要で、それぞれ何を定義するのか |
| STD-003 | [設計書作成規約](00_標準定義/03_設計書作成規約.md) | どのようなルールで書くのか |

## 使い方（プロジェクトへの適用）

1. 設計書体系定義書の「要否判断フロー」で、作成する設計書を決める。
2. 結果を「設計書適用台帳（DOC-002）」に記録する。
3. テンプレートをコピーし、作成ガイドと作成規約に従って記載する。
4. 標準の不足・過剰に気づいたら改善要望として記録し、標準に反映する。
